# Communication Platform — Phase 5 Lifecycle Policy

Scope: `PARCEL_DELIVERY` threads (and `MERCHANT_DESK` where noted). Principle: **conversations and messages are never deleted or auto-closed by logistics events**; access follows live eligibility, and membership rows are reconciled to match it. Only rules supported by existing business behaviour are implemented — no new automatic closing was invented.

Rules that apply everywhere:

- **No auto-create:** lifecycle events only affect threads someone already opened.
- **No deletion:** messages, participants (status only) and audit rows are retained; deleted message content follows the Phase 2 soft-delete rule only for user/moderator deletions.
- **Moderator removals are final for the workflow:** a user removed by a moderator is never re-admitted automatically, even when eligible again; a moderator must re-add them.
- **Merchant desk:** unaffected by parcel events; one per merchant, merchant-only tenant scope; admin joins existing desks only with a reason.
