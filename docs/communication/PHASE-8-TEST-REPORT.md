## 5. Environment incidents (honest account)

1. The 200-VU ramp exhausted the Docker Desktop VM (~3.8 GiB): the engine crashed and stopped all containers on the machine, including other projects' containers. Docker Desktop was relaunched; those containers restarted automatically (restart policies). Load profiles were then resized.
2. `TaskStop` on backgrounded `bash … node` / `npx next start` left Node children running; the first Chromium browser run hit a stale Phase 7 web server on port 3100 and was discarded and repeated after the stale processes were stopped. Ports were verified free afterwards.
3. Two synthetic-data scripts failed because `psql -c` with several statements runs in one transaction (a `VACUUM` error rolled back the load); re-run correctly. One unintended consequence: a GIN option experiment was initially rolled back and re-done.
4. External auto-staging: Phase 8 files appear staged in the git index although no `git add` was run.
