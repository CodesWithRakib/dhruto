# Communication Platform — Phase 8 Security Assessment

Scope: all communication code paths for ADMIN, MERCHANT, RIDER, HUB_MANAGER and CUSTOMER (no SUPERADMIN exists). Method: code review, existing and new integration tests on disposable infrastructure, browser tests, and tooling (gitleaks, semgrep, pnpm audit). No testing against shared or production systems.

## 6. Residual risks accepted by design (documented)

Presigned GET URLs are bearer URLs for 5 minutes; ADMIN reads are audited, not prevented; ≤ 60 s ephemeral (typing/presence) revocation window; at-least-once realtime delivery with client gap-fill; ClamAV is signature-based (no sandboxing).
