# W7 — COD → Hand-in → Verify → Settlement → Payout

1. **Goal:** Collected COD → hub-verified → merchant-settled → withdrawn. Auditable, transactional, idempotent, reconcilable.
2. **Preconditions:** delivered parcel with `CashLedger`; rider hand-in; hub verify; admin settle/approve.
3. **Entry:** `/rider/profile` (cash summary + hand-in) → `/hub/cash` (`hub-cash-desk`: pending/batches/discrepancies) → `/admin/finance` (overview/payouts/settlements/batches/journal/adjustments/reports/check) → `/merchant/finance` (wallet/statement/payouts/settlements + request modal).
4. **Journey:** rider `POST /riders/me/cash/hand-in {notes?}` (+Key) → `CashHandIn(handin_code UQ, expected/verified_minor bigint) + CashHandInItem{cash_ledger UQ}` → hub `POST /finance/reconciliation/verify {cashLedgerUUID, actualAmount?, notes}` → `CashLedger.verified_amount` + `Settlement{gross/fee/net bigint, settlement_code UQ, parcel UQ, ledger UQ}` → admin batch `POST /admin/finance/settlements/batches {merchantUUID, settlementIds[1-500]}` → `complete` → merchant `POST /finance/payouts/request {amount≥100, method/accountDetails}` (+Key, `10/60`) → admin `approve` → `process {COMPLETED/FAILED/REJECTED}` → `Wallet{merchant UQ, balance/pending/withdrawn decimal12,2} + WalletTransaction` + double-entry `FinancialTransaction{transaction_code UQ, immutable} + FinancialEntry{amount_minor>0, RESTRICT, merchantId}`.
5. **Entities:** `CashLedger/HandIn/Item/Discrepancy + Settlement/Batch + Wallet/Tx + PayoutRequest{payout_code, (merchant,idempotency) UQ} + FinancialTransaction/Entry + IdempotencyRecord`.
6. **Failures:** double-verify serialize; SHORT variance → `CashDiscrepancy(expected/actual/difference bigint, UQ ledger)` → admin `resolve {recovered, reason}`; payout state machine (PENDING→APPROVED→COMPLETED/FAILED/REJECTED, cancel only pending); reversal `POST /transactions/:id/reverse {reason}` (immutable + compensating entry, never delete); adjustments `CREDIT|DEBIT` (+Key).
7. **Success:** balanced journals (`sum(entries)==0` per tx); `reconciliation/check` clean; CSV reports (`reports/cod|payouts|fees ?format=csv`).
8. **Downstream:** notifications (`payout_requested/completed`), analytics finance/COD, audit logs.
9. **Edge:** zero-count verify (`actualAmount @IsPositive` blocks 0 — confirm intended); concurrent payout requests; reversal of settled batch (`cancelSettlementBatch` has NO route — orphan service method).
10. **Missing:** auto-settlement schedule; bank-transfer integration (manual `process` + refs); merchant invoice PDF.
11. **Tests:** API `finance.e2e-spec.ts` (9: full journey), `finance-ledger.e2e-spec.ts` (13: invariants/concurrency/reversal/batches/CSV); web `finance-merchant/hub/admin.spec.ts (2 each) + finance-bn-spot + finance-mobile`; seed `seed-finance.data.ts`, `seed-wallets.data.ts`.
